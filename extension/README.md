# Vex Wallet Extension

Non-custodial multi-chain wallet with quantum-resistant layer.

## Load unpacked
1. chrome://extensions or edge://extensions
2. Developer mode
3. Load unpacked → select the extension folder

## Features
- Create / Import wallet
- Real Solana + EVM addresses
- ML-DSA quantum key
- Send SOL
- Click-to-copy addresses
- Balances
